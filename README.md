# JavaScript Assignments 4

This project implements the three tasks in the provided assignment PDF.

## Included tasks
1. **Live Input & Character Guard** — live username character counter and password-length feedback.
2. **Subscription Plan Selector & Form Guard** — plan details update on selection; submission requires accepting the terms.
3. **Dynamic Registration & Profile Card Builder** — validates name, matching passwords, and role; creates a profile card when valid.

## Run the project
1. Extract the ZIP file.
2. Open `index.html` in a web browser.
3. Try each task in its section.

## Files
- `index.html` — page structure and forms
- `style.css` — responsive styling
- `script.js` — JavaScript event listeners and validation
